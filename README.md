# Chenxiao Fan's Academic Homepage

Source code for [cxfann.github.io](https://cxfann.github.io), built with [PRISM](https://github.com/xyjoey/PRISM).

## Local development

Requires Node.js 22 or later.

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run lint
npm run build
```

The static site is exported to `out/` and deployed to GitHub Pages through GitHub Actions.
